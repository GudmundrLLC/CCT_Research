# Scheduled research reports

The CCT Research Hub web app is the lab's interactive library. Recurring literature
reports are produced separately, by one scheduled Claude task that saves Google Docs
to a shared Drive folder.

| Item | Detail |
|---|---|
| Schedule | Every day at 04:43 America/Denver |
| Daily | Scan of the window since the last report |
| Weekly | Mondays: review of the past 7 days |
| Monthly | 1st of the month: ranked trends for the past 30 days |
| Quarterly | 2 Jan/Apr/Jul/Oct: progress against the proposal's aims |
| Annual | 3 Jan: review of the whole field |
| Output | Drive folder "CCT-TRiC Research — Aaron Wilson PhD", with subfolders Daily, Weekly, Monthly, Quarterly and Annual |
| Steering | The "00 Research Brief" doc in that folder sets the proposal aims, search terms, sources, rules, and the list of items already logged. Edit it to change what runs look for. |
| Extra input | Files dropped in "0 Inbox", or shared by Neila or Aaron, are folded into the next report. |
| Sources | PubMed E-utilities, Europe PMC, bioRxiv/medRxiv API, Crossref, NIH RePORTER, and web search |

Reports are read against Aaron Wilson's third-year proposal (BYU, Willardson lab):

- Aim 1: mLST8 folding.
- Aim 2: Anticarin β.
- Aim 3: Gβ1/Gβ5 mutants.
